# NN from scratch

Logistic regression and a two-layer neural network written in plain NumPy, trained on the breast cancer dataset.

## What's in it
Each model has an `explore.ipynb`, and `notes/` has my equations and shape notes. Both notebooks check the gradients numerically.

## How to run
Open a notebook in `logistic-regression/` or `two-layer-network/` and run it top to bottom. It needs numpy, pandas, scikit-learn and matplotlib.

## Status
Logistic regression is done and the two-layer network is still in progress.
